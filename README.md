Plant Disease Detection

A project that trains a model to detect plant diseases, and provides a web app interface (using Streamlit) for inference.

Contents

main.py — the Streamlit app / main inference script

trained_plant_disease_model.keras — the trained model for plant disease classification

training_hist.json — training history of model (loss/accuracy over epochs)

Notebooks:

Train_plant_disease.ipynb / Train_plant_disease-checkpoint.ipynb — for training the model

Test_plant_disease.ipynb / Test_plant_disease-checkpoint.ipynb — for testing / evaluation

Assets:

Diseases.png — sample disease images or a summary

.streamlit, settings.json — app configuration

requirements.txt — dependencies

Requirements

You’ll need:

Python (version compatible with the model libraries used)
